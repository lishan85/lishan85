## Projects

- **[dsh-wander](https://github.com/lishan85/dsh-wander)** — DeepSeek Harness 插件：用户空闲时挑一个公开授权的路边摄像头取快照，写成第一人称旅行日记，下次对话时注入系统提示。
  `TypeScript` `Node.js` `DeepSeek Harness`
- **[Fatigue-detection-model](https://github.com/lishan85/Fatigue-detection-model)** — 摄像头实时疲劳检测：YOLOv12 人脸检测 + MediaPipe Face Mesh，用 EAR / MAR / 头部姿态在 10 秒窗口内判断疲劳并告警。
  `Python` `YOLOv12` `MediaPipe` `OpenCV`
- **[novel-ai-detox](https://github.com/lishan85/novel-ai-detox)** — Codex Agent Skill：由 controller 调度 reader / worker agents 迭代点评与改写网文章节，降低 AI 味，同时保留情节事实。
  `Codex Skill` `Multi-agent` `Prompt Engineering`

另外还在 fork 的 [dsh-companion](https://github.com/lishan85/dsh-companion)（基于 tr1v3r/dsh-ltm）上做 DeepSeek Harness 长期陪伴/记忆插件，并接入 dsh-wander 的出行记录。
